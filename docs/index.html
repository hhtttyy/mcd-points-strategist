你的积分不是攒出来的，是漏掉的

基于麦当劳中国 MCP 数据结构的积分资产分析器。 拖动滑块模拟你的积分余额，立刻看清：积分衰减了多少、兑换档位哪个真划算、 有没有在为早已结束的活动白攒分、以及最优兑换组合怎么选。

这是离线演示版，用合成数据驱动，展示的是算法内核。
页面数据的字段结构与麦当劳 MCP 真实响应完全一致（券的时段/星期/渠道限制、 商城标的的上下架时间都按真实契约填充），但账户数字与券面值经过改写， 不是任何真实账户的数据。
实时看板与「每天检测 → 合理花出 → 变动自动更新」的完整闭环在 WorkBuddy 里 —— 把本仓库装成 Skill 后直接对话使用即可，脚本会实时拉取你的真实数据。 本页与 Skill 跑的是同一份 points-engine.mjs，结论永远一致。
